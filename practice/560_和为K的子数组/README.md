# 和为 K 的子数组

- 来源：LeetCode
- 题号：560
- 英文名：Subarray Sum Equals K
- 难度：中等
- 核心标签：数组、哈希表、前缀和
- 链接：https://leetcode.cn/problems/subarray-sum-equals-k/

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的子数组的个数。

子数组是数组中元素的连续非空序列。

## 输入与输出

- 输入：整数数组 `nums`、整数 `k`
- 输出：和为 `k` 的连续非空子数组的个数
- 约束：
  - `1 <= nums.length <= 2 * 10^4`
  - `-1000 <= nums[i] <= 1000`
  - `-10^7 <= k <= 10^7`

## 示例

### 示例 1

- 输入：`nums = [1,1,1]`，`k = 2`
- 输出：`2`

### 示例 2

- 输入：`nums = [1,2,3]`，`k = 3`
- 输出：`2`
